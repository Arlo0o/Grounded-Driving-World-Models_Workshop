# Selected Works figure provenance

On November 7, 2026, the workshop organizer explicitly confirmed that author
permission had been obtained to display teasers/main figures for all seven
Spotlight papers on the workshop website.

Copyright remains with the respective authors/rightsholders. This permission is
for workshop website display; no general reuse license, whole-paper publication,
source-code release, or arXiv redistribution permission is implied.

Each image is a render of the selected original PDF figure, without redrawing,
generative edits, or changes to results. Crops omit surrounding manuscript text.
Full source PDFs are not included in this repository. Captions on the website
are short descriptive labels; figure numbers refer to the submitted versions.
Images are approximately 1600 pixels wide and are served locally as WebP.
